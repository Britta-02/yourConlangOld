Write your notes about chapter 1.

Iat-order can be applied in different ways.

adding options:
1. Without the ability to add options. The data-popup-source, inputfield-icon, btn-edit and btn-close buttons can be deleted.
2. With the ability to add options using text-add. The data-popup-source, inputfield-icon, btn-edit and btn-close buttons can be deleted and replaced by the commented out code.
3. With the ability to add options using popup-add. The data-popup-source, inputfield-icon, btn-edit and btn-close buttons are needed and The comented out code can be removed.

lists:
4. With only the ord-available list. The ord-used div must stay, but all buttons wihtin it can be removed
5. With only the ord-used list. The whole ord-available div can be deleted.
6. With botht the ord-available and ord-used list.

You can choose one of the adding options options and you can choose one of the lists options.
